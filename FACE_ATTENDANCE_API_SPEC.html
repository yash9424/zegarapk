Face Attendance — API Spec

Zegar app • Backend: PHP Laravel + MySQL • Base URL: https://zedgift.viaaratech.com/api
Setup: ONE shared phone (kiosk). Face recognition is done in the app (ML Kit + MobileFaceNet). The server only needs to (1) store each employee's face embeddings, and (2) save the punch (attendance).

Headers on every request: Authorization: Bearer <token> , Company-ID: <id> , Accept: application/json
Response formats: date = DD-MM-YYYY, time = 12-hour (e.g. 09:05 AM).

1) Register Face NEW

Admin enrols an employee. The app captures 5 angles, makes one embedding per angle, and sends them. The server stores them for that employee.

Endpoint
POST /attendance/face/register      (Content-Type: multipart/form-data)
Request fields — with data types
FieldTypeRequiredDescription
employee_idintegerYesthe employee's id (from /employees)
embeddingsJSON stringYesarray of vectors; each vector = 192 decimal numbers (float)
face_imagefile (jpg/png)Noone photo, kept on record only
Mock example — request
POST /attendance/face/register
employee_id = 1038
embeddings  = [
  [0.0123, -0.0821, 0.1140, 0.0335, ... total 192 numbers ...],
  [0.0201, -0.0772, 0.1002, 0.0419, ... total 192 numbers ...],
  [0.0098, -0.0810, 0.1185, 0.0288, ... total 192 numbers ...]
]
face_image  = yash_face.jpg
Mock example — response
{
  "success": true,
  "message": "Face registered successfully.",
  "data": {
    "employee_id": 1038,
    "embeddings_count": 3
  }
}

2) Mark Attendance (Punch) EXISTS - confirm

After the app recognizes the employee (on the phone), it sends a punch. The server saves it and auto-decides IN or OUT (first punch of the day = IN, next = OUT).

Endpoint
POST /attendance/punch              (Content-Type: multipart/form-data)
Request fields — with data types
FieldTypeRequiredDescription
employee_idintegerYesrecognized employee's id
typestringNo"face"
timestampstring (datetime)Noformat: YYYY-MM-DD HH:MM:SS (24h, server time ok)
Mock example — request
POST /attendance/punch
employee_id = 1038
type        = face
timestamp   = 2026-06-09 09:05:00
